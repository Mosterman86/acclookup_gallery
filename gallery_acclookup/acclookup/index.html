The Wolfsonian–FIU Image Lookup & Gallery Maker

Wolfsonian Digital Labs — Image Tools Proof of Concept

Accession Image Lookup & Gallery Maker

Search the Wolfsonian image archive by accession number, review thumbnails and metadata, and compile selections into a shareable gallery.

About this project

This tool is an early proof of concept for browsing and retrieving digitized images from the Wolfsonian collection by accession number. It is part of an ongoing initiative within the Wolfsonian Digital Labs to build browser-based tools that connect staff and researchers to collection assets without requiring access to backend systems.

The lookup interface reads from a master image inventory CSV and resolves file paths to a thumbnail delivery service, allowing users to verify image coverage, preview assets, and export selections. The gallery output is designed to support internal reviews, donor presentations, and curatorial workflows. As with all Digital Labs proofs of concept, formats, workflows, and features will continue to evolve.

How it works

On load, the tool fetches two Excel-derived data files in parallel. The first is an image inventory mapping accession numbers to file paths on network storage. The second contains descriptive metadata exported from the Wolfsonian's collections system, with fields including title, date created, place of publication, and description. The two files are joined in the browser on the shared accession number key.

Three search modes are available: Exact Search matches accession numbers precisely; Begins With Search returns all records starting with a given prefix, useful for retrieving an entire collection group; and Non-Exact Search performs a substring match for broader lookups. Results render as a table with thumbnails delivered via the Wolfsonian thumbnail service, which proxies and resizes images from network storage paths on demand. Clicking any thumbnail opens a full-resolution lightbox powered by Fancybox.

Selecting one or more results and clicking Create Gallery encodes the image paths and metadata into the URL and navigates to the companion gallery view, where selected objects are presented as a tile grid. The encoded URL can be copied and shared with colleagues using the Share Gallery button. The Export Selected (PDF) function renders the results table to a downloadable PDF using html2canvas and jsPDF.
